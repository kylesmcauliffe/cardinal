# URL sheet

Every route the static build emits (608 pages). Generated by `node scripts/url-sheet.mjs` from `dist/`.

The site builds for any base path: `WOP_BASE=/some/path/ npm run build`. Routes below are relative to that base. Query strings are not routes, but two are supported on `/`.

## Fixed routes

| Route | What it is |
|---|---|
| `/` | The web of people: drag, zoom, click for a profile |
| `/?p=<person-id>` | The web with that person’s profile open (shareable). Example: `/?p=leland-stanford` |
| `/?p=place:<place-id>` | The web with a place hub’s panel open. Example: `/?p=place:stanford-ca` |
| `/?p=org:<org-id>` | The web with an organisation hub’s panel open. Example: `/?p=org:fairchild-semiconductor` |
| `/people/` | All 215 people, filterable (relatives named only through family links included) |
| `/family/` | Families the notes document, drawn as trees, and a pointer to import |
| `/surnames/` | 75 surnames |
| `/places/` | 89 places |
| `/organisations/` | 13 organisations with sourced members |
| `/charts/` | Four charts drawn from the dataset |
| `/import/` | Load a GEDCOM file in the browser (stretch feature) |
| `/sources/` | The repository files behind every fact, with weight |
| `/404.html` | Not-found page |
